# sdd-practice Constitution

## Core Principles

### I. Stack fijo

Todo código de aplicación se escribe en **Go** con **SQLite3**, usando templates HTML renderizados en servidor con **HTMX**. Otro stack solo si el usuario lo pide explícitamente en esa misma petición.

### II. Idioma

Toda interacción con el usuario, la documentación y los specs se escriben en **español dominicano**. En inglés quedan solo los términos técnicos: identifiers, keywords, comandos CLI, nombres de archivos, mensajes de commit.

## Governance

- Esta constitution aplica a todos los artifacts de Spec Kit (spec, plan, tasks) y a cualquier código que salga del ciclo.
- Enmiendas: las pide el usuario y se documentan aquí con fecha.
